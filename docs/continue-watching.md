# Emby 首页继续观看

Nook 的 Emby 兼容首页将断点续播和下一集推荐合并为一个「继续观看」列表。

| 观看状态 | 首页显示 |
| --- | --- |
| 电影未看完 | 原电影，保留用户的播放位置 |
| 剧集当前集未看完 | 当前集，保留播放位置 |
| 当前集已看完，后面有未看集 | 下一集；尚未播放时进度为 0 |
| 已看完最后一集 | 不再显示该剧，不恢复更早的旧断点 |

同一部剧只保留一个条目，按这部剧最近一次观看的时间参与整体排序。没有观看历史的剧不会自动进入列表。播放记录按 Nook 用户隔离，继续应用媒体库访问权限、成人内容隐藏和已删除媒体过滤。

## 接口约定

- `GET /emby/Users/:userId/Items/Resume` 与 `/emby/Items/Resume` 返回合并列表，支持 `Limit`、`StartIndex`，以及通过 `ParentId` / `SeriesId` 收窄范围。小写别名保持可用。
- `GET /emby/Items?Filters=IsResumable` 保留原意：只返回真正存在未完成播放位置的条目，不加入尚未播放的下一集。
- 首页不再提供单独的 NextUp 内容：不带剧集作用域的 `GET /emby/Shows/NextUp` 返回合法的空列表。此行为也适用于不读取服务器首页偏好的客户端，避免两个栏目返回相同卡片。
- `GET /emby/Shows/NextUp?SeriesId=…`、`/emby/Shows/:id/NextUp` 等按剧查询继续返回该剧当前应看的集，供详情页「继续播放」使用。当前集未看完时仍返回它本身。
- DisplayPreferences 默认保留 `homesection1: resume`，将原来的独立 `homesection3: nextup` 改为 `none`。

## 远程挂载与边界

挂载的远程 Emby 使用 Nook 本地播放历史计算续播和下一集，不使用上游共享账号的观看状态。远程媒体按挂载权限过滤，并支持按远程媒体库、剧或季收窄。

候选范围为最近 200 条有效播放历史，单页最多 100 项。先按剧去重、按观看时间排序，再分页。本地条目总数准确；远程详情仅按当前页面需要并发补齐，未补齐候选的总数沿用上界估算，以避免为了统计而请求全部远程历史。远程读取共用 8 秒预算，慢源或不可用条目不会阻止其余本地内容返回。

不新增数据库表或列，不删除现有观看进度。升级后客户端可能需要刷新首页以更新缓存的栏目。已验证 HTTP 协议流程及模拟远程服务器，尚未做 SenPlayer 真机升级联调。
