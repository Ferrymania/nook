# 媒体识别简化规则

2026-10-15：按最新要求，采用 qmediasync 的电影/剧集分别处理和季年份校验思路，独立实现适合 Nook 的保守规则。本文取代此前完整方案中的复杂候选打分、身份来源扩展和自动推断设计。

## 自动确认只做几件事

1. 保留现有文件名、目录、显式 ID 和季集解析。单片目录有明确中文名时先查中文；中英文混排分别保留中文和英文搜索词。分类目录不参与片名搜索。
2. 名称只接受规范化后的完整标题、原名或提供者返回的可信别名。取消共同词百分比和候选打分，保留明确续集编号的规范化。
3. 同一查询只有一个符合名称、类型和年份的作品 ID 才自动确认。同一个 ID 的重复结果视为一条；多个 ID 同时符合则停止自动识别，提示手动匹配，不按排序、热度或海报选择。
4. 来源有明确中文名时，英文候选还需能解释该中文名：匹配标题或可信别名即可。译名无法核实时留给手动；仅有英文的来源不强制补中文。
5. 电影继续允许相邻上映年差异，但年份相同不能补偿片名不符。空结果或无合格结果时保留已有的有界别名/语言/年份回退。
6. S02 及之后的剧集不使用季年份过滤整剧首播年。先按完整名称确认唯一整剧；来源含年份时，再读取对应季的播出年核对。季信息缺失、请求失败或年份不同则不自动确认。

现有提供者和手动匹配入口继续使用。名字近似、译名不明、同名翻拍无法区分等情况，直接交给手动匹配，不增加 AI 推断、演员交叉评分或新的数据库表。

## 实施细节

- 自动刮削与整理入口共享完整名称规则和歧义处理。
- 搜索缓存加入季号，避免其他季复用本季校验结果；整剧首播年和已校验季年份分别保留在本次查询上下文。
- 歧义原因使用现有队列错误字段：“多个候选符合名称和年份条件，请手动匹配”。媒体仍使用现有未匹配状态。
- 歧义不能被旧 NFO 回退标记成成功。强制重新匹配也不回退到旧 NFO 身份，成功后不再用旧 NFO 覆盖新身份。
- 不重做既有 ID/NFO 来源模型。已有错误资料通过手动重新匹配纠正；本次规则变更不在生产库自动改写历史记录。
- 保留已发布的 Part 分集、特别篇、半集和同集多版本保护。

## 验收

- `Yi Yi` 不再匹配 `Xiang yi nian nian`；完整可信别名 `Yi Yi` 仍可确认《一一》。
- `Legend of the Dragon` 不再接受多出 `Lost` 的名称；明确中文目录优先，无法核对的译名转人工。
- 中英混排保留 `The Pitt`，但不能单凭英文通过就忽略中文来源冲突。
- 两个同名同年 ID 返回待手动匹配；唯一但不相关的结果也不接受。
- 《秘密森林》S02 的 2020 年按季校验，整剧首播年继续保存为 2017；其他季、缺失季和错误年份不能复用 S02 缓存。
- 显式续集编号、准确名称、可信别名、相邻电影年份、Part 分集的现有正常情况继续验证。
